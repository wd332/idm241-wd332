Rules

Exhibition Card:

  • Hover On
    • expands image from the center slightly by 15%
    • cursor changes to the finger
    • ease in with a duration of 0.53s
      • left & right arrows appear on top of the image
      • page indicators appear on top of the image
      • a glow of white, 25% opacity drop shadow with a blur of 100 and spread of 10 at origin surrounds the border of the card
  • Hover Off
    • back to default state
      • shrinks image back
      • cursor returns to normal
    • ease out
      • left & right arrows
      • page indicators
      • drop shadow
  • Click On
    • view exhibit details on another page

Left Arrow

  • Hover On
    • background color eases with 0.2s to 40% opacity
  • Hover Off
    • background color returns to default state
  • Click on
    • image will slide in from the left

Right Arrow

  • Hover On
    • background color eases with 0.2s to 40% opacity
  • Hover Off
    • background color returns to default state
  • Click on
    • image will slide in from the right

On View Box:

  • Hover On
    • a popup text called "This is available now" expands out towards the top right with a bounce/spring in a duration of 0.9s
  • Hover Off
    • the text shrinks back into the box with a ease out of 0.9s

Page Indicators:

  • Click On
    • corresponding image to the indicator will replace the current image if need be
    • eases with 0.3s to 60% opacity with 31px width
    • previously selected indicator will return to default state of 30% opacity with 15px width
